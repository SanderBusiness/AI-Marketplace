# web-design-guidelines

Reviews UI code against Vercel's [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines):
accessibility, focus, forms, animation, typography, performance, navigation state, theming,
i18n and copy. Findings come back as clickable `file:line` items.

Adapted from [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)
(MIT). See [`skills/web-design-guidelines/SKILL.md`](./skills/web-design-guidelines/SKILL.md).
